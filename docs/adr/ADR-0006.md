# ADR-0006: Phase 01 module contracts and readiness

Status: Accepted engineering baseline
Date: 2026-11-08

## Context
Phase 01 requires concrete contracts, ownership, security boundaries and verifiable readiness without scaffolding.

## Decision
Use docs/architecture/PHASE-01-BASELINE.md as the engineering baseline. Application contracts own cross-module interactions, private queries are actor-scoped, and source fingerprints identify the original documents. Calendar/session/reminder/content-coverage proposals remain explicitly unresolved until their relevant phase.

## Alternatives considered
Starting application scaffolding now would exceed Phase 01. Marking all architecture requirements implemented from documentation would overstate evidence.

## Consequences and follow-up
Phase 02 can proceed. Feature phases must demonstrate runtime conformance, update traceability and summarize usable functionality. No new product approval is inferred.
