# ADR-0012: Private workspace and reviewed song identities

Status: Accepted engineering decision
Date: 2026-11-08

Workspace typed items provide owner-scoped CRUD with database-backed collection links, dates and status. Minimal reviewed song references are a prerequisite for favorites/song-linked records; no public song content or invented seeds added. Shared references are separated from private owner rows. Tradeoff: legacy notes and temporary catalogue code placement need consolidation with full catalogue/export features; preserve existing data. Cascade private data on account deletion, unlink deleted collections, restrict referenced song removal. API ownership tests cover all kinds.
