# ADR-0002: Cookie sessions and private ownership

Status: Accepted
Date: 2026-11-08
Decision owner: project owner (explicit product decisions); engineering proposals remain marked.

## Context
Requirements, blueprint and final user clarifications must agree without inventing approval or provider rights.

## Decision
Use server-managed secure opaque-cookie sessions and backend actor-derived ownership. Custom chords/patterns remain private; specified guest tools remain public.

## Alternatives considered
JWT browser storage and public sharing were considered but not selected by the user.

## Consequences and follow-up
Implement revocation, expiration, CSRF and negative authorization tests in phase 05; policy constants remain proposed.
