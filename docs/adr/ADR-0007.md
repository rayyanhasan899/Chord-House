# ADR-0007: Phase 02 runtime and dependency foundation

Status: Accepted engineering decision
Date: 2026-11-08

## Context
The existing Windows environment has Node 24 and Python 3.14. Phase 02 needs reproducible local scaffolding, not feature implementation.

## Decision
Use npm workspaces and Next.js 16.4.5/React 19.3.1 with TypeScript/Tailwind 4 and shadcn-compatible aliases/configuration. Use FastAPI 0.162.2 and Python 3.14 in a local virtual environment. Commit npm and Python development locks. Use Ruff/mypy, ESLint/Prettier, Pytest, Vitest/RTL and Playwright Chromium with initial GitHub Actions. shadcn components and app shell remain Phase 06.

## Alternatives considered
No separate frontend repository, mandatory uv or global runtime downgrade; no database service before phase 03. Deployment runtime compatibility will be evaluated before choosing providers.

## Consequences
Existing local runtime works. Browser smoke test and empty API OpenAPI prove the skeleton, not learning features. Development-only minimatch advisories remain documented; production audit is clean. Full OpenAPI type generation follows backend API foundation. No backend business endpoints or migrations introduced early.
