# ADR-0005: Local operation and deployment independence

Status: Accepted
Date: 2026-11-08
Decision owner: project owner (explicit product decisions); engineering proposals remain marked.

## Context
Requirements, blueprint and final user clarifications must agree without inventing approval or provider rights.

## Decision
Complete local frontend/backend/PostgreSQL operation; prepare replaceable free hosting adapters and select providers only after fresh evaluation.

## Alternatives considered
Hosted-only core and mandatory paid APIs conflict with user decisions.

## Consequences and follow-up
No final provider yet; account authorization and secrets handled securely before deployment.
