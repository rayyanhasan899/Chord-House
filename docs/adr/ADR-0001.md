# ADR-0001: Layered modular monolith

Status: Accepted
Date: 2026-11-08
Decision owner: project owner (explicit product decisions); engineering proposals remain marked.

## Context
Requirements, blueprint and final user clarifications must agree without inventing approval or provider rights.

## Decision
Preserve the supplied stack and inward dependencies; use feature-owned contracts and local browser audio.

## Alternatives considered
Microservices add cost and coupling without an observed scaling need.

## Consequences and follow-up
Feature isolation remains testable; migrations and composition are mandatory.
