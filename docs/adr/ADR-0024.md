# ADR-0024: Measured quality and compatibility evidence

Date: 2026-11-11. Status: accepted engineering choices for Phase 18.

## Context and decisions

Quality work must distinguish deterministic correctness, real browser processing,
production-build measurements and physical instrument/output-device observations.
Passing generated signals cannot certify a microphone, guitar, speaker latency or
GuitarTuna comparison. The owner's available setup is the current computer and
Google Chrome. The owner asked the agent to perform the checks itself; no further
physical measurements are inferred and no arbitrary E2/A2 correction is applied.

Run the entire existing browser suite in Chromium, Firefox and WebKit, plus a
focused quality suite in mobile Chromium/WebKit emulation. Installed stable
Chrome/Edge channels are opt-in with `CHORD_BRANDED_BROWSERS=1` and are tested on
Windows with isolated browser profiles. Emulation does not establish physical
iPhone/Android support, and WebKit is not a branded Safari certification.

Use the official Playwright 1.65.0 Noble image, matching the locked package, with
an Ubuntu 24.04 runner for its Python runtime. This avoids the observed Ubuntu
font/dependency DNS failure without removing any browser assertions. Its root
test context is for trusted local fixtures only; the application still runs as
the separately verified non-root preview user. This is a quality prerequisite,
not a hosting/provider selection or Phase 19 rollout. Native Linux browser clocks use an explicitly configured PulseAudio null output; this is not a physical speaker measurement. The container uses Ubuntu’s official signed HTTPS archive after the Azure/security mirrors failed DNS. Serial CI browser execution bounds memory and avoids resource-induced browser crashes.

The performance gates are engineering regression budgets, not newly approved
product SLAs: local production DOM-ready below 10 seconds, script transfer below
1.5 MB, worker response below 2 seconds and each disposable 5,000-record search
below 5 seconds. Retain raw measurements, first versus warm requests, sample
counts, browser versions and environment. Do not call these measurements public
mobile-network, field-vitals or high-concurrency capacity evidence.

## Catalog optimization and privacy

Profiling exposed unnecessary full arrangement/lyric parsing for every search
match. List responses now validate a lightweight read projection and perform live
metadata/component grant, expiry and withdrawal checks. Full content validation
remains at write/detail boundaries; differential tests compare list/detail counts,
availability and pagination after rights changes. No result cache, stale rights
window, public guest song access, new content or provider permission is introduced.
Status/language indexes and streaming bounded response pages remain; substring
matching still scans candidates. Measure before adding extensions or indexes.

Audio startup is bounded to five seconds with recovery guidance, and tuner Start waits for actual context closure after Stop. Stale worker/track callbacks cannot stop a newer capture. Progress table scrolling is explicitly keyboard focusable. No schema migration is needed; head remains `0012_integration`. Provider backup
configuration and restore rehearsal remain explicitly assigned Phase 19 gates.
Local reproducible text uses LF through `.gitattributes` so Windows checkout
conversion cannot masquerade as a format regression.

## Evidence and limitations

See `../architecture/QUALITY-AND-COMPATIBILITY.md` and the Phase 18 report for
executed commands, actual results and unresolved device gaps. Do not interpret
this ADR or engineering budgets as physical calibration, independent certification,
provider approval or permission to merge or start Phase 19.

Primary references: [Playwright browsers](https://playwright.dev/docs/browsers),
[emulation](https://playwright.dev/docs/emulation),
[official Docker runtime](https://playwright.dev/docs/docker), and the installed
Next 16.4.5 production checklist. The official registry tags were checked for the
matching `v1.65.0-noble` image before use.

Operational refinement (2026-11-12): signed Ubuntu package acquisition uses bounded fallbacks across the official archive, Kernel Archives and MIT mirrors after DNS/TCP failures. Ubuntu signature and TLS checks remain enabled. Start the PulseAudio daemon without the client PULSE_SERVER selector, then connect clients to its private Unix socket. Chord startup can be cancelled with Stop; stale rejected starts cannot close newer playback or overwrite its feedback.
