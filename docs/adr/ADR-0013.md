# ADR-0013: Browser-local worker tuner

Status: Accepted engineering decision; physical calibration pending
Date: 2026-11-08

Use local Web Audio capture and a dedicated pitch worker, not a paid service or uploaded recordings. YIN-style normalized difference, confidence gate, bounded frequency range and interpolation support low-bass through ukulele references. Manual target selection prevents false in-tune results on another string. Worker back-pressure and 100ms sampling avoid blocking UI. Stop/unmount releases all resources; generation counter handles delayed capture/results. Synthetic/reference and real browser tests pass; they do not establish real-microphone accuracy. Full Phase 08 acceptance awaits measured instrument/reference-tuner comparison.
