# ADR-0020: Derived progress and private learning roadmap

Status: Accepted. Date: 2026-11-09. Calendar rules explicitly accepted by owner reply; remaining details are engineering choices within Phase 14.

Compute progress from saved active UTC intervals, never cached aggregate counters. Allocate exact integer microseconds at local midnight boundaries using IANA timezone rules. Day lengths can be 23/25 hours. The owner's current profile timezone determines the calendar; captured session timezone remains untouched. Monday begins a week. Any positive allocated saved time qualifies a practice day. A current streak can end yesterday while today is still open. Future portions do not count. All queries filter authenticated owner.

Use repeatable-read transactions to keep profile/session/goal reads coherent. Updates/deletes/timezone edits therefore recalculate automatically on next read. UI refreshes on navigation, focus, visibility and a 60-second interval; explicit refresh is available. Unsaved weekly reflections suspend automatic refresh. Rank linked session totals only: routine activity time is not inferred as song/chord time. Statistics are evidence of recorded time, not playing ability.

Daily historical target results use the version effective at local day close, weekly results at week close; current target progress uses now. Paused/unconfigured goals have no result. Goal changes never remove sessions. Weekly review (UNI-025 selected MAY) covers completed Monday-start weeks and stores only optional private reflection text/version; time and goal results are always derived.

Eight original roadmap milestones adapt technique guidance to instrument and prioritize selected skill level. Completions are self-reported, per account and selected instrument, independent of recorded practice; no completion or learning assessment is fabricated. Profile instrument switches preserve other instruments' marks. Account deletion cascades new records. Migration 0010 adds only completions/reflections and no aggregates. Existing content rights, guest tool policy and Phase 13 session rules are unchanged.
