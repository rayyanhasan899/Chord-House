# ADR-0016: Validated private rhythms and one audio transport

Accepted: 2026-11-08, Phase 11.

Represent each pattern as one measure: supported meter, 1/2/4 equal steps per denominator-note beat, and exactly beats × subdivision D/U/R/X strokes. D/U are down/up, R is a silent rest, X is a synthesized muted stroke. Require at least one sounding stroke, valid metadata and ordered suggested tempo range 30–300. Framework-independent Rhythm enforces these rules through API validation; SQL enforces visibility, FK, meter, level and tempo invariants.

Shared patterns have no owner and are draft/published/archived. Private patterns have a non-null account owner and private status only. Separate role-checked manager endpoints cannot convert a private pattern into shared content. Publication requires explicit review, rights statement and attribution. Archive/unpublish hides shared records immediately on subsequent API reads; favorites remain private and reappear if republished. Original exercise seeds have stable IDs and never overwrite managed records. This is not a licensed song arrangement catalogue.

Patterns require sign-in under existing access policy; guest access beyond the three approved tools is not inferred. Select STR-018 MAY: private custom patterns are included. Full manager UI and broader content audit workflows remain Phase 15, but actual create/read/update/publish/unpublish/archive use cases are executable now via API.

Extract one AudioTransport for metronome and pattern players. One context, one 25 ms scheduling timer, one visual frame loop; combined pattern/metronome uses the same subdivision timeline and context. Settings changes stop pattern playback rather than silently modifying queued rhythms. Start resumes audio by gesture, stop/navigation releases it, suspension asks for restart. Synthetic direction/strum timing does not claim recorded guitar realism or physical output latency.
