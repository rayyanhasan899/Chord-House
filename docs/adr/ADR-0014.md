# ADR-0014: Chord reference generation and private fingering storage

Status: Accepted engineering decision
Date: 2026-11-08

Public reference voicings are original structured shapes/transpositions behind the feature music module, with complete pitch-class and fingering validation. No copyrighted chart artwork or recordings imported. Generation makes coverage predictable at zero cost; finger/difficulty guidance is explicitly not expert-reviewed. Public catalogue persistence/admin editing can replace this provider in Phase 15. Private customs use PostgreSQL ownership FKs and validated JSONB fret/finger arrays. Pure domain validation is separate from transport/ORM; backend is authoritative. Browser audio creates bounded envelopes and releases context on stop/end/unmount. This avoids paid audio services and uploaded recordings.
