# ADR-0010: Cookie identity and local mail

Status: Accepted engineering decision
Date: 2026-11-08

## Decision
PostgreSQL-backed opaque sessions, hashed verifiers, Argon2id, strict Origin/CSRF checks, role guards and database rate buckets. Adopt initial 24h idle/7d absolute expiry. Single-use 30-minute verification/reset codes use local private capture or configured SMTP. Production requires HTTPS origins and SMTP. Deletion requires verified email, password and confirmation.

## Alternatives and consequences
JWT browser storage and mandatory hosted identity were not selected. No Redis needed. SMTP retries, timing-side-channel review and full export remain later hardening work. OAuth unselected. UI follows Phase 06. Tests use PostgreSQL and temporary mail capture without external delivery.
