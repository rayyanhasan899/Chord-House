# Browser-local tuner

Guest route /tuner supports acoustic/electric standard, Drop D, DADGAD, standard bass and re-entrant ukulele. MIDI references preserve physical string order. Frequencies use A4=440 Hz; deviation is 1200 log2(detected/target). Target selection is manual to prevent another string being labelled in tune. The visible five-cent band is a target, not a measured hardware guarantee.

Audio capture starts only on explicit action. An 8192-sample analyser feeds a dedicated worker every 100 ms with back-pressure; audio is never posted to an HTTP endpoint or recorded. Stop/unmount terminates worker/timer, stops tracks and closes the audio context. A generation counter handles pending permissions and stale worker results. Permission, unsupported-device and disconnection errors are shown. Input-level feedback indicates silence/clipping; low clarity suppresses pitch. UI smoothing is reset on unreliable input.

Detector: averaged 4:1 downsampling, YIN-style cumulative mean normalized difference, 0.12 threshold/local minimum and parabolic lag interpolation; search approximately 30–1100 Hz. RMS threshold .003 rejects weak input. This bounded filter/search is intentionally monophonic. Complex noise, missing fundamentals, inharmonic strings and microphone high-pass filtering may cause errors; physical bass E1 must be measured separately. Reference: de Cheveigne/Kawahara (2002), https://pubmed.ncbi.nlm.nih.gov/12002874/ . Published algorithm results are not claims about this implementation.

Automated evidence: generated clean/strong-harmonic reference fixtures at 44.1/48 kHz across all preset pitches pass the ±5-cent target; deterministic noise, weak signals and silence rejected. Native browser oscillator→MediaStream→analyser→worker test reaches in-tune for E2, checks zero POST audio traffic, stop/unmount track release and denied permission. These synthetic fixtures do not verify a real microphone, real guitar or low-bass recording.

Physical calibration gate remains OPEN: use a known reference tuner with real guitar/bass/ukulele on representative devices. Record device/browser/sample rate/reference frequency, detected Hz/cents, settling time, noise and harmonics; include E1 41.20 Hz, all strings, Drop D/DADGAD and re-entrant ukulele. Do not mark TUN-049/051 or full Phase 08 acceptance verified before those measurements exist. Hardware availability was asked in chat; no response is assumed.
